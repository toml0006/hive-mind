# Changelog

All notable changes will be documented here. The project follows
[Semantic Versioning](https://semver.org/) once it reaches its first tagged
release.

## Unreleased

### Added

- Temporal canonical decisions with explicit supersession.
- Valid-time and transaction-time queries.
- Immutable correction history in the web app.
- MCP tools, prompt hooks, and candidate review queue.
- Local Neo4j development stack.
- Public contribution, governance, security, and community documentation.

### Changed

- Removed the private path dependency from the distributable Python package.
- Made repository mappings local configuration instead of public project data.
- Made semantic grounding a provider-neutral optional extension point.
